# JNIEL's Body Massage and Spa

A PHP and MySQL-based web application for managing spa appointments, customers, services, and therapists.

## Technologies

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP

## Features

- Customer registration and login
- Spa appointment booking
- Appointment management
- Service management
- Therapist management
- Customer management
- Email OTP verification
- Appointment reminders
